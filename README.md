# RPKI RP Benchmark Test Suite

This repository provides implementations of the test cases for IETF Internet-Draft 
[Benchmarking Methodology for RPKI Relying Party](https://datatracker.ietf.org/doc/draft-qin-bmwg-rpki-rp-bench/).
The test suite covers the test points for evaluating the RP validation behaviors specified by the document.

The test cases are built for use with the following existing tools:

- [BaRRy](https://github.com/LACNIC/barry) generates valid or deliberately malformed RPKI repositories from repository descriptor (`rd`) files.
- [Rapport](https://github.com/LACNIC/rapport) provides the test framework for running RPs against repositories generated by BaRRy and evaluating their validation results.

BaRRy and Rapport are independent upstream projects and are not included in this repository. They must be obtained and installed separately.

## Using the Test Suite

This repository provides `benchmark_tests` implementations and is not a standalone test runner.

To execute the test suite, users must integrate it into a local Rapport environment and provide an RP adapter script appropriate for the implementation being tested.

Refer to the [Rapport documentation](https://github.com/LACNIC/rapport) for its standard installation, RP adapter, and test execution mechanisms.

## Test Results

The `reports` directory contains the per-testcase results and summary reports obtained for the following RP implementations:

- FORT 1.6.7
- Routinator 0.15.2
- rpki-client 9.8 
- rpki-prover v0.10.1

A test case is reported as **Pass** when the observed RP behavior and output match the expected result defined by the test case; reported as **Fail** when the observed result differs from the expected result.

The reported results apply only to the specific RP versions and configurations identified in each report and may differ for other versions or configurations.
